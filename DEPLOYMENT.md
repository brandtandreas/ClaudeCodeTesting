# Deployment Guide

This app is designed to run for free on:
- **Frontend**: [Vercel](https://vercel.com)
- **Backend**: [Render](https://render.com)
- **Database**: [Neon](https://neon.tech) (serverless Postgres)

---

## 1. Database — Neon

1. Sign up at https://neon.tech and create a new project (name it `chess-trainer`)
2. Neon creates a default database. Copy the **connection string** — it looks like:
   ```
   postgres://user:password@ep-xxx.us-east-2.aws.neon.tech/neondb?sslmode=require
   ```
3. Keep this — you'll paste it into Render in the next step

---

## 2. Backend — Render

1. Sign up at https://render.com and click **New → Web Service**
2. Connect your GitHub repo
3. Render will detect `render.yaml` automatically — confirm the settings
4. Under **Environment Variables**, fill in the two `sync: false` values:
   - `DATABASE_URL` → paste your Neon connection string
   - `CORS_ORIGIN` → paste your Vercel deployment URL (do this after Vercel is set up; redeploy if needed)
5. Click **Deploy**
6. Once deployed, open the **Shell** tab in Render and run:
   ```bash
   npm run db:migrate --workspace=backend
   npm run db:seed --workspace=backend
   ```
7. Verify the service is healthy by visiting `https://<your-render-url>/health` — should return `{"status":"ok"}`

> **Note:** The free Render tier spins down after 15 minutes of inactivity. The first request after sleep takes ~30 seconds. Upgrade to the $7/month Starter plan to keep it always-on.

---

## 3. Frontend — Vercel

1. Sign up at https://vercel.com and click **Add New → Project**
2. Import your GitHub repo
3. Vercel detects `vercel.json` automatically — no framework override needed
4. Under **Environment Variables**, add:
   - `VITE_API_BASE_URL` → your Render backend URL (e.g. `https://chess-trainer-api.onrender.com`)
5. Click **Deploy**
6. Your app will be live at `https://<your-project>.vercel.app`

---

## Environment Variables Summary

| Service | Variable | Value |
|---------|----------|-------|
| Render | `DATABASE_URL` | Neon connection string |
| Render | `JWT_SECRET` | Auto-generated by Render |
| Render | `CORS_ORIGIN` | Vercel deployment URL |
| Render | `NODE_ENV` | `production` (set in render.yaml) |
| Render | `PORT` | `3001` (set in render.yaml) |
| Vercel | `VITE_API_BASE_URL` | Render backend URL |

---

## Local Development

```bash
cp backend/.env.example backend/.env   # fill in DATABASE_URL, JWT_SECRET
npm install
npm run db:migrate --workspace=backend
npm run db:seed --workspace=backend
npm run dev                             # Vite on :5173, Fastify on :3001
```
